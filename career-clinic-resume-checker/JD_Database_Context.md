### 3.2 Field dictionary

| Field | Type | Meaning / use |
|---|---|---|
| `id` | string `DOM-SUB-NN` | Permanent key. Prefix = `domainCode`. |
| `domain`, `domainCode`, `subDomain`, `role` | string | Dropdown levels 1–3 and the role title. |
| `levels` | `("Campus"\|"Early"\|"Mid"\|"Senior")[]` | Multi-tag. Campus 0–2 yrs, Early 2–5, Mid 5–10, Senior 10+ (one JD). Show the JD under every tagged level. |
| `industry` | string (16 tags) | Filter chip: BFSI, Consulting, E-commerce/Retail, EdTech, Energy, FMCG, IT/ITeS, Infrastructure, Legal Services, Logistics, Manufacturing/Auto, Media, Pharma/Healthcare, Public/Development, SaaS/Tech, Telecom. |
| `employerType`, `locations` | string, string[] | Generic employer type (never a real company) and typical Indian locations. |
| `summary`, `responsibilities` | string, string[6–10] | Preview and JD text. |
| `requiredSkills`, `goodToHave`, `tools` | string[] | As written on the card. |
| `experience` | `{ text, minYears, maxYears, freshersEligible }` | `maxYears` 15 means "10+/12+" (open-ended). |
| `education` | string | Degree line as written. |
| `academicCutOff` | `{ code, note }` | `AC-C` campus (60% norm at mass recruiters), `AC-E` early lateral, `AC-M` mid, `AC-L` legal. **Advisory only — never scored.** |
| `certifications` | `{ required, preferred }` | Human-readable text. |
| `atsKeywords` | string[10–15] | Keywords a matching resume should contain. Used as preferred hard skills. |
| `status` | `{ code: "V"\|"P"\|"A", note }` | V verified pattern (19), P partially verified (66), A assumption-led (52). Show as a confidence label. |
| `flags` | string[] | FLAG notes (lateral role, employer-variable criteria). Show to the user. |
| `lateral` | boolean | Usually hired laterally, rarely a fresher hire. |
| `track` | `"mba"\|"llb"\|"hybrid"` | Legal roles: `llb` needs an LLB; `hybrid` is open to MBA graduates. |
| `regulatoryWarning` | string \| null | Set for 6 regulated roles (FIN-EQR-01, FIN-WM-01, SAL-RB-01, LGL-CORP-01, LGL-CS-01, LGL-LIT-01). Show prominently. |
| `scoring` | object | Precomputed inputs for `JDFacts` — see 3.3. Not sent to the client. |

### 3.3 How the `scoring` fields were derived (INFERENCE — review with calibration data)

The MCC Fit Score v1 caps a resume at 69 when **any** must-have skill or the required degree is missing, so these fields are deliberately conservative:

- **`mustHaveSkills`** — technical items from the card's "Required skills", at most 5. Behavioural items go to **`softSkills`**. 17 JDs have no technical must-have (e.g. PR, general-management and some sales roles) and therefore no skills knockout.
- **Preferred hard skills** are built at runtime by `toJDFacts()` from `atsKeywords` plus `goodToHave` (deduplicated with `normalise()`).
- **`requiredDegrees`** — substring tokens matched against the resume's education text by `scoring.ts`. 76 JDs carry a degree gate: MBA tokens (MBA, PGDM, MMS, PGP, PGDBA and long forms) or, for 4 LLB-track roles, LLB tokens. An empty array means no degree gate, used where the JD accepts alternatives (CA, LLB, any graduate) or says "preferred".
- **`preferredSpecialisations`** — taken from the education line (e.g. Finance, Marketing, HR/Human Resource, Operations, Supply Chain, Analytics).
- **`requiredCertifications`** — canonical names for 10 JDs: FIN-CTR-01, FIN-EQR-01, FIN-WM-01, FIN-TAX-01, SAL-RB-01, OPS-PEX-01, LGL-CORP-01, LGL-IHC-01, LGL-CS-01, LGL-LIT-01. The current scorer matches these by exact normalised string (education factor only, 15% of 8 points). `certs.ts` adds pattern matching used for user warnings; Task 9 (optional) applies it inside the scorer.
- **`roleFamily`** — mapped onto the scorer's 9-value enum. 25 JDs (General Management, PR & Communications, Legal, Entrepreneurship, Public Policy, ESG) map to `"other"`. FLAG: consider extending the enum (`general_management`, `communications`, `legal`, `investment_banking`, `supply_chain`, `it_systems`) in a future schema version.
- **`freshersRole`** = `experience.minYears === 0`; **`minExperienceMonths`** = `minYears × 12`.

### Task 1 — Extraction script and npm script

Create `scripts/extract-jd-library.mjs`:

```js
// Extracts the JD library JSON from the Antigravity context file, verifies it, and writes src/data/jd-library.v1.json.
// Usage: node scripts/extract-jd-library.mjs [path/to/context.md]
import fs from "node:fs";
import path from "node:path";
import crypto from "node:crypto";

const src = process.argv[2] ?? "docs/MyCareerCompany_JD_Library_Antigravity_Context.md";
const out = "src/data/jd-library.v1.json";
const md = fs.readFileSync(src, "utf8");

const block = md.match(/<!-- JD_LIBRARY_JSON_START -->\s*```json\s*([\s\S]*?)```\s*<!-- JD_LIBRARY_JSON_END -->/);
if (!block) throw new Error("JD library JSON block not found between the START/END markers.");
const expectedSha = md.match(/JD_LIBRARY_SHA256:\s*([a-f0-9]{64})/)?.[1];
const expectedCount = Number(md.match(/JD_LIBRARY_COUNT:\s*(\d+)/)?.[1]);

const data = JSON.parse(block[1]);
if (!Array.isArray(data)) throw new Error("Expected a JSON array of JD records.");
if (data.length !== expectedCount) throw new Error(`Expected ${expectedCount} records, found ${data.length}.`);
const ids = data.map(d => d.id);
if (new Set(ids).size !== ids.length) throw new Error("Duplicate JD IDs found.");
const sha = crypto.createHash("sha256").update(JSON.stringify(data)).digest("hex");
if (expectedSha && sha !== expectedSha) throw new Error(`Checksum mismatch: file ${sha} vs header ${expectedSha}. The data block was edited or truncated.`);

fs.mkdirSync(path.dirname(out), { recursive: true });
fs.writeFileSync(out, JSON.stringify(data, null, 2) + "\n");
console.log(`Wrote ${out}: ${data.length} sample JDs across ${new Set(data.map(d => d.domain)).size} domains (sha256 ${sha.slice(0, 12)}…).`);
```

Add to `package.json` → `"scripts"`: `"jd:extract": "node scripts/extract-jd-library.mjs"`. Run `npm run jd:extract` and commit `src/data/jd-library.v1.json`. Confirm `tsconfig.json` has `"resolveJsonModule": true` (Next.js default).

### Task 2 — `src/lib/jdLibrary.ts`

```ts
// MyCareerCompany — Target JD Sample Library (data access + conversion to JDFacts)
// Source of truth: src/data/jd-library.v1.json (extracted from the Antigravity context file).
// Safe to import on the server only (large JSON). Client components must use /api/jds.
import { z } from "zod";
import raw from "../data/jd-library.v1.json";
import { JDFacts } from "./schemas";
import { normalise } from "./skills";

export const LIBRARY_VERSION = "jdlib-2026.10-v1";
export const LEVELS = ["Campus", "Early", "Mid", "Senior"] as const;
export const STATUS_CODES = ["V", "P", "A"] as const;
export const CUTOFF_CODES = ["AC-C", "AC-E", "AC-M", "AC-L"] as const;
export const ROLE_FAMILIES = ["consulting", "product", "marketing", "sales", "finance", "analytics", "operations", "hr", "other"] as const;
export const STATUS_LABEL: Record<(typeof STATUS_CODES)[number], string> = {
  V: "Verified pattern", P: "Partially verified", A: "Assumption-led",
};
export const SAMPLE_DISCLAIMER =
  "Sample JDs are illustrative composites for resume-matching practice. They are not live vacancies, and a high match does not guarantee shortlisting or placement.";

export const SampleJD = z.object({
  id: z.string().regex(/^[A-Z]{3}-[A-Z0-9]{2,4}-\d{2}$/),
  domain: z.string().min(2),
  domainCode: z.string().length(3),
  subDomain: z.string().min(2),
  role: z.string().min(2),
  levels: z.array(z.enum(LEVELS)).min(1),
  industry: z.string().min(2),
  employerType: z.string().min(2),
  locations: z.array(z.string()).min(1),
  summary: z.string().min(50).max(300),
  responsibilities: z.array(z.string()).min(6).max(10),
  requiredSkills: z.array(z.string()).min(1),
  goodToHave: z.array(z.string()),
  tools: z.array(z.string()),
  experience: z.object({ text: z.string(), minYears: z.number().min(0), maxYears: z.number().min(0), freshersEligible: z.boolean() }),
  education: z.string().min(2),
  academicCutOff: z.object({ code: z.enum(CUTOFF_CODES), note: z.string() }),
  certifications: z.object({ required: z.string(), preferred: z.string() }),
  atsKeywords: z.array(z.string()).min(10).max(15),
  status: z.object({ code: z.enum(STATUS_CODES), note: z.string() }),
  flags: z.array(z.string()),
  lateral: z.boolean(),
  track: z.enum(["mba", "llb", "hybrid"]),
  regulatoryWarning: z.string().nullable(),
  scoring: z.object({
    roleFamily: z.enum(ROLE_FAMILIES),
    freshersRole: z.boolean(),
    minExperienceMonths: z.number().int().min(0),
    requiredDegrees: z.array(z.string()),
    preferredSpecialisations: z.array(z.string()),
    requiredCertifications: z.array(z.string()),
    mustHaveSkills: z.array(z.string()).max(5),
    softSkills: z.array(z.string()),
  }),
});
export type SampleJD = z.infer<typeof SampleJD>;

// Validate once at module load: a malformed library must fail the build/tests, not a user request.
export const JD_LIBRARY: readonly SampleJD[] = Object.freeze(z.array(SampleJD).parse(raw as unknown));
const BY_ID = new Map(JD_LIBRARY.map(j => [j.id, j] as const));

export function getSampleJD(id: string): SampleJD | null {
  return BY_ID.get(id) ?? null;
}

// ---------- Dropdown taxonomy: Domain › Sub-domain › Role (level and industry are filters) ----------
export interface RoleOption { id: string; role: string; levels: string[]; industry: string; status: string; experience: string }
export interface SubDomainNode { name: string; roles: RoleOption[] }
export interface DomainNode { domain: string; domainCode: string; count: number; subDomains: SubDomainNode[] }

export function getTaxonomy(filter: { level?: string; industry?: string } = {}): DomainNode[] {
  const out: DomainNode[] = [];
  for (const j of JD_LIBRARY) {
    if (filter.level && !j.levels.includes(filter.level as SampleJD["levels"][number])) continue;
    if (filter.industry && j.industry !== filter.industry) continue;
    let d = out.find(x => x.domain === j.domain);
    if (!d) { d = { domain: j.domain, domainCode: j.domainCode, count: 0, subDomains: [] }; out.push(d); }
    let s = d.subDomains.find(x => x.name === j.subDomain);
    if (!s) { s = { name: j.subDomain, roles: [] }; d.subDomains.push(s); }
    s.roles.push({ id: j.id, role: j.role, levels: j.levels, industry: j.industry, status: j.status.code,
      experience: j.experience.maxYears >= 15 ? `${j.experience.minYears}+ yrs` : `${j.experience.minYears}–${j.experience.maxYears} yrs` });
    d.count++;
  }
  return out; // preserves library order (B1 Consulting … B28 EdTech)
}

export function listIndustries(): string[] {
  return [...new Set(JD_LIBRARY.map(j => j.industry))].sort();
}

export function searchSampleJDs(q: string, limit = 20): SampleJD[] {
  const t = q.trim().toLowerCase();
  if (t.length < 2) return [];
  return JD_LIBRARY.filter(j =>
    [j.id, j.role, j.domain, j.subDomain, ...j.atsKeywords].some(f => f.toLowerCase().includes(t))).slice(0, limit);
}

// ---------- Conversion for the deterministic scorer ----------
// Sample JDs skip LLM extraction: their JDFacts are precomputed, so the same resume always gets the same score.
export function toJDFacts(j: SampleJD): JDFacts {
  const must = j.scoring.mustHaveSkills;
  const mustN = new Set(must.map(normalise));
  const preferred: string[] = [];
  for (const k of [...j.atsKeywords, ...j.goodToHave.map(g => g.replace(/\s*\([^)]*\)/g, "").trim())]) {
    const n = normalise(k);
    if (!n || mustN.has(n) || preferred.some(p => normalise(p) === n)) continue;
    preferred.push(k);
  }
  return JDFacts.parse({
    title: j.role,
    roleFamily: j.scoring.roleFamily,
    freshersRole: j.scoring.freshersRole,
    minExperienceMonths: j.scoring.minExperienceMonths,
    requiredDegrees: j.scoring.requiredDegrees,
    preferredSpecialisations: j.scoring.preferredSpecialisations,
    requiredCertifications: j.scoring.requiredCertifications,
    hardSkills: [...must.map(name => ({ name, mustHave: true })), ...preferred.map(name => ({ name, mustHave: false }))],
    softSkills: j.scoring.softSkills,
  });
}

// Plain-text JD used for the suggestions prompt and for display/download.
export function toJDText(j: SampleJD): string {
  return [
    `${j.role} (sample JD ${j.id}) — ${j.employerType} · ${j.locations.join(", ")}`,
    `Domain: ${j.domain} › ${j.subDomain} · Level: ${j.levels.join(" / ")} · Industry: ${j.industry}`,
    `About the role: ${j.summary}`,
    `Key responsibilities:\n${j.responsibilities.map(r => `- ${r}`).join("\n")}`,
    `Required skills: ${j.requiredSkills.join("; ")}`,
    `Good to have: ${j.goodToHave.join("; ")}`,
    `Tools: ${j.tools.join("; ")}`,
    `Experience: ${j.experience.text}`,
    `Education: ${j.education}`,
    `Academic criteria (${j.academicCutOff.code}): ${j.academicCutOff.note}`,
    `Certifications — required: ${j.certifications.required}`,
    `Certifications — preferred: ${j.certifications.preferred}`,
    `Keywords: ${j.atsKeywords.join(", ")}`,
  ].join("\n\n");
}

// Notes the UI should show next to a sample-JD result (never folded into the score).
export function sampleNotes(j: SampleJD) {
  return {
    id: j.id, libraryVersion: LIBRARY_VERSION,
    status: { code: j.status.code, label: STATUS_LABEL[j.status.code], note: j.status.note },
    academicCutOff: j.academicCutOff, // advisory only — do not score
    regulatoryWarning: j.regulatoryWarning,
    flags: j.flags,
    disclaimer: SAMPLE_DISCLAIMER,
  };
}
```

### Task 3 — `src/lib/certs.ts`

```ts
// Pattern-based certificate matching for required credentials in the JD library.
// Exact string matching misses common resume spellings such as "NISM Series V A" or "Chartered Accountant (ICAI)".
import { normalise } from "./skills";

export const CERT_PATTERNS: Record<string, RegExp> = {
  "NISM-Series-XV": /nism[\s-]*(series[\s-]*)?xv\b|research analyst certification/i,
  "NISM-Series-V-A": /nism[\s-]*(series[\s-]*)?v[\s-]*a\b|mutual fund distributor/i,
  "IRDAI certification": /irdai|ic[\s-]*38|insurance (agent|bancassurance|specified person)/i,
  "Bar Council enrolment": /bar council|enrolled advocate|advocate enrol/i,
  "AIBE": /\baibe\b|all india bar exam/i,
  "ACS": /\bacs\b|associate company secretary|icsi (associate|member)/i,
  "Lean Six Sigma Green Belt": /(lean\s*)?six\s*sigma.*green\s*belt|\blssgb\b/i,
  "CA": /\b(ca|aca|fca)\b(?![-\s]*(inter|intermediate|foundation))|chartered accountant/i,
};
export function certMatches(required: string, resumeCerts: string[]): boolean {
  const rx = CERT_PATTERNS[required];
  return rx ? resumeCerts.some(c => rx.test(c)) : resumeCerts.some(c => normalise(c) === normalise(required));
}
```

```ts
// Resolves the Target JD for /api/check from one of: sample (library), link (URL), upload (PDF/DOCX), paste (text).
import "server-only";
import { lookup } from "node:dns/promises";
import { isIP } from "node:net";
import { MAX_BYTES, sniffType } from "./security";
import { parseResume } from "./parse";
import { getSampleJD, toJDFacts, toJDText, sampleNotes, LIBRARY_VERSION } from "./jdLibrary";
import type { JDFacts } from "./schemas";

export type JDSource = "sample" | "link" | "upload" | "paste";

export class JDInputError extends Error {
  constructor(message: string, public status = 400) { super(message); }
}

export interface ResolvedJD {
  source: JDSource;
  text: string;                       // full JD text (untrusted unless source === "sample")
  facts: JDFacts | null;              // precomputed for sample JDs; null → run LLM extraction as before
  sampleId: string | null;
  libraryVersion: string | null;
  urlHost: string | null;             // store the host only, never the page HTML
  notes: ReturnType<typeof sampleNotes> | null;
}

const MIN_JD_CHARS = 200;
const MAX_JD_CHARS = 20_000;
const LINK_TIMEOUT_MS = 8_000;
const LINK_MAX_BYTES = 1_500_000;
const MAX_REDIRECTS = 3;

export async function resolveJD(form: FormData): Promise<ResolvedJD> {
  const source = String(form.get("jdSource") ?? "paste") as JDSource;
  switch (source) {
    case "sample": {
      const j = getSampleJD(String(form.get("jdId") ?? ""));
      if (!j) throw new JDInputError("Choose a sample JD from the list.");
      return { source, text: toJDText(j), facts: toJDFacts(j), sampleId: j.id, libraryVersion: LIBRARY_VERSION, urlHost: null, notes: sampleNotes(j) };
    }
    case "link": {
      const { text, host } = await fetchJobPage(String(form.get("jdUrl") ?? "").trim());
      return external(source, text, host);
    }
    case "upload": {
      const f = form.get("jdFile");
      if (!(f instanceof File) || f.size === 0) throw new JDInputError("Attach the JD as a PDF or DOCX file.");
      if (f.size > MAX_BYTES) throw new JDInputError("The JD file must be 2 MB or smaller.");
      const buf = Buffer.from(await f.arrayBuffer());
      const type = sniffType(buf);
      if (!type) throw new JDInputError("Upload the JD as PDF or DOCX (no macro-enabled files).");
      return external(source, (await parseResume(buf, type)).text, null);
    }
    case "paste":
      return external(source, String(form.get("jd") ?? ""), null);
    default:
      throw new JDInputError("Unknown JD source.");
  }
}

function external(source: JDSource, raw: string, urlHost: string | null): ResolvedJD {
  const text = raw.replace(/\r/g, "").trim().slice(0, MAX_JD_CHARS);
  if (text.length < MIN_JD_CHARS) {
    throw new JDInputError(source === "link"
      ? "We couldn't read enough of that page. Some job boards need a login or block automated access. Paste the JD text or upload it instead."
      : "The JD looks too short. Include the full job description (at least 200 characters).");
  }
  return { source, text, facts: null, sampleId: null, libraryVersion: null, urlHost, notes: null };
}

// ---------- Link intake with SSRF protection ----------
async function fetchJobPage(input: string): Promise<{ text: string; host: string }> {
  let url: URL;
  try { url = new URL(input); } catch { throw new JDInputError("Enter the full job link, starting with https://"); }
  for (let hop = 0; hop <= MAX_REDIRECTS; hop++) {
    await assertPublicHttps(url);
    const res = await fetch(url, {
      redirect: "manual",
      signal: AbortSignal.timeout(LINK_TIMEOUT_MS),
      headers: {
        "user-agent": "MyCareerCompany-ResumeChecker/1.0 (+https://www.mycareercompany.com)",
        accept: "text/html,application/xhtml+xml,text/plain;q=0.9,application/pdf;q=0.8",
      },
    }).catch(() => { throw new JDInputError("That link didn't respond in time. Paste or upload the JD instead."); });
    if (res.status >= 300 && res.status < 400) {
      const loc = res.headers.get("location");
      if (!loc) break;
      url = new URL(loc, url);
      continue;
    }
    if (!res.ok) throw new JDInputError(`That page returned an error (${res.status}). Paste or upload the JD instead.`);
    const buf = await readCapped(res, LINK_MAX_BYTES);
    const ctype = (res.headers.get("content-type") ?? "").toLowerCase();
    const sniffed = sniffType(buf);
    if (sniffed) return { text: (await parseResume(buf, sniffed)).text, host: url.hostname };
    if (!/text\/html|application\/xhtml|text\/plain/.test(ctype)) throw new JDInputError("That link isn't a web page or PDF we can read.");
    const body = buf.toString("utf8");
    return { text: ctype.includes("text/plain") ? body : htmlToJobText(body), host: url.hostname };
  }
  throw new JDInputError("That link redirects too many times. Paste or upload the JD instead.");
}

async function assertPublicHttps(url: URL): Promise<void> {
  if (url.protocol !== "https:") throw new JDInputError("Only https:// links are supported.");
  if (url.username || url.password) throw new JDInputError("Links with embedded credentials aren't supported.");
  if (url.port && url.port !== "443") throw new JDInputError("Links with custom ports aren't supported.");
  const host = url.hostname.replace(/^\[|\]$/g, "");
  let addrs: { address: string }[];
  if (isIP(host)) addrs = [{ address: host }];
  else {
    try { addrs = await lookup(host, { all: true, verbatim: true }); }
    catch { throw new JDInputError("We couldn't find that website. Check the link."); }
  }
  if (!addrs.length || addrs.some(a => isPrivateIP(a.address))) throw new JDInputError("That link points to a private network address.");
}

export function isPrivateIP(ip: string): boolean {
  const v = ip.toLowerCase();
  if (v.includes(":")) {
    if (v.startsWith("::ffff:")) return isPrivateIP(v.slice(7));
    return v === "::" || v === "::1" || /^f[cd]/.test(v) || /^fe[89ab]/.test(v);
  }
  const [a, b] = v.split(".").map(Number);
  return a === 0 || a === 10 || a === 127 || a >= 224 ||
    (a === 100 && b >= 64 && b <= 127) || (a === 169 && b === 254) ||
    (a === 172 && b >= 16 && b <= 31) || (a === 192 && b === 168) || (a === 198 && (b === 18 || b === 19));
}

async function readCapped(res: Response, max: number): Promise<Buffer> {
  if (Number(res.headers.get("content-length") ?? 0) > max) throw new JDInputError("That page is too large to read.");
  if (!res.body) return Buffer.alloc(0);
  const reader = res.body.getReader();
  const chunks: Uint8Array[] = [];
  let total = 0;
  for (;;) {
    const { done, value } = await reader.read();
    if (done) break;
    total += value.byteLength;
    if (total > max) { await reader.cancel(); throw new JDInputError("That page is too large to read."); }
    chunks.push(value);
  }
  return Buffer.concat(chunks);
}

// Prefer schema.org JobPosting JSON-LD (used by many careers sites); fall back to visible text.
export function htmlToJobText(html: string): string {
  for (const m of html.matchAll(/<script[^>]*type=["']application\/ld\+json["'][^>]*>([\s\S]*?)<\/script>/gi)) {
    try {
      const data: unknown = JSON.parse(m[1].trim());
      const items = (Array.isArray(data) ? data : [data]).flatMap((d: any) => (d && d["@graph"]) ? d["@graph"] : [d]);
      const jp: any = items.find((d: any) => ([] as unknown[]).concat(d?.["@type"] ?? []).includes("JobPosting"));
      if (jp?.description) {
        const exp = jp.experienceRequirements;
        return [
          jp.title ? String(jp.title) : "",
          jp.hiringOrganization?.name ? `Company: ${jp.hiringOrganization.name}` : "",
          stripTags(decodeEntities(String(jp.description))),
          jp.qualifications ? `Qualifications: ${stripTags(decodeEntities(String(jp.qualifications)))}` : "",
          exp ? `Experience: ${typeof exp === "string" ? exp : JSON.stringify(exp)}` : "",
        ].filter(Boolean).join("\n\n");
      }
    } catch { /* ignore malformed JSON-LD */ }
  }
  const main = html.match(/<(main|article)\b[\s\S]*?<\/\1>/i)?.[0] ?? html.match(/<body\b[\s\S]*<\/body>/i)?.[0] ?? html;
  return stripTags(main);
}

function stripTags(s: string): string {
  return decodeEntities(
    s.replace(/<(script|style|noscript|svg|nav|footer|header|form)\b[\s\S]*?<\/\1>/gi, " ")
      .replace(/<br\s*\/?>|<\/(p|div|li|h[1-6]|tr|section)>/gi, "\n")
      .replace(/<li\b[^>]*>/gi, "- ")
      .replace(/<[^>]+>/g, " "),
  ).replace(/[ \t\f\v]+/g, " ").replace(/\n[ \t]*/g, "\n").replace(/\n{3,}/g, "\n\n").trim();
}

function decodeEntities(s: string): string {
  return s.replace(/&nbsp;/g, " ").replace(/&lt;/g, "<").replace(/&gt;/g, ">").replace(/&quot;/g, '"')
    .replace(/&#39;|&apos;/g, "'").replace(/&#(\d+);/g, (_, n) => String.fromCodePoint(Number(n)))
    .replace(/&#x([0-9a-f]+);/gi, (_, h) => String.fromCodePoint(parseInt(h, 16))).replace(/&amp;/g, "&");
}
```

```ts
import { adminAuth, db, bucket } from "@/lib/firebaseAdmin";
import { MAX_BYTES, sniffType, sanitize, redactPII, wrapUntrusted } from "@/lib/security";
import { parseResume } from "@/lib/parse";

import { certMatches } from "@/lib/certs";
import { FieldValue } from "firebase-admin/firestore";

export const runtime = "nodejs";
export const maxDuration = 60;

export async function POST(req: NextRequest) {
  const t0 = Date.now();
  // 1. Auth
  const token = req.headers.get("authorization")?.replace("Bearer ", "");
  if (!token) return NextResponse.json({ error: "login required" }, { status: 401 });
  const { uid } = await adminAuth.verifyIdToken(token).catch(() => ({ uid: "" }));
  if (!uid) return NextResponse.json({ error: "invalid session" }, { status: 401 });
  const consent = await db.doc(`users/${uid}`).get();
  if (!consent.get("consent.v1")) return NextResponse.json({ error: "consent required" }, { status: 403 });

  // 2. Rate limit
  const day = new Date().toISOString().slice(0, 10);
  const rl = db.doc(`usage/${uid}_${day}`);
  const used = (await rl.get()).get("count") ?? 0;
  if (used >= Number(process.env.DAILY_CHECK_LIMIT ?? 10)) return NextResponse.json({ error: "daily limit reached" }, { status: 429 });

  // 3. Validate input: resume + Target JD (sample / link / upload / paste)
  const form = await req.formData();
  const file = form.get("resume") as File | null;
  if (!file || file.size > MAX_BYTES) return NextResponse.json({ error: "PDF/DOCX up to 2 MB required" }, { status: 400 });
  let target: ResolvedJD;
  try { target = await resolveJD(form); }
  catch (e) { if (e instanceof JDInputError) return NextResponse.json({ error: e.message }, { status: e.status }); throw e; }
  const buf = Buffer.from(await file.arrayBuffer());
  const type = sniffType(buf);
  if (!type) return NextResponse.json({ error: "only PDF or DOCX (no macros)" }, { status: 400 });

  // 4. Store original (private bucket, asia-south1)
  const resultRef = db.collection(`users/${uid}/checks`).doc();
  await bucket.file(`resumes/${uid}/${resultRef.id}.${type}`).save(buf, { resumable: false, contentType: file.type, metadata: { metadata: { uid } } });

  // 5. Parse + sanitize
  const parsed = await parseResume(buf, type);
  const r = sanitize(redactPII(parsed.text)); const j = sanitize(target.text);

  // 6. Extract (LLM, schema-validated). Sample JDs use precomputed JDFacts — no LLM call, fully deterministic.
  const [resume, jd] = await Promise.all([
    generateJSON({ task: "extract", name: "resume", schema: ResumeFacts, system: EXTRACT_RESUME_SYS, user: wrapUntrusted("RESUME", r.clean) }),
    target.facts ?? generateJSON({ task: "extract", name: "jd", schema: JDFacts, system: EXTRACT_JD_SYS, user: wrapUntrusted("JD", j.clean) }),
  ]);

  // 7. Embeddings + deterministic score
  const resumeSkills = [...resume.skillsListed, ...resume.certifications];
  const titles = [resume.headline ?? "", ...resume.roles.map(x => x.title)].filter(Boolean);
  const [jdSkills, rSkills, jdTitle, rTitles] = await Promise.all([
    embed(jd.hardSkills.map(s => s.name)), embed(resumeSkills), embed([jd.title]), embed(titles),
  ]);
  const result = score(resume, jd, parsed, { jdSkills, resumeSkills: rSkills, jdTitle: jdTitle[0] ?? [], resumeTitles: rTitles }, resumeSkills);
  if (r.injectionFlag) result.warnings.push("Hidden or instruction-like text found in resume; remove it.");
  // Sample JDs: flag missing statutory / commonly required credentials (advisory text only; the score is unchanged).
  if (target.sampleId) {
    const s = getSampleJD(target.sampleId);
    const missing = (s?.scoring.requiredCertifications ?? []).filter(c => !certMatches(c, resume.certifications));
    if (missing.length) result.warnings.push(`Required credential not found on your resume: ${missing.join(", ")}.`);
  }

  // 8. Suggestions (LLM) + truth guard
  const raw = await generateJSON({
    task: "write", name: "suggestions", schema: Suggestions, system: WRITE_SYS,
    user: `RESUME_FACTS:\n${JSON.stringify(resume)}\n\nJD_FACTS:\n${JSON.stringify(jd)}\n\nGAPS:\n${JSON.stringify({ missingMust: result.missingMustHave, missingPreferred: result.missingPreferred, warnings: result.warnings })}`,
  });
  const suggestions = enforceTruth(raw, resume);

  // 9. Persist + audit (no resume text in logs)
  await resultRef.set({ createdAt: FieldValue.serverTimestamp(), modelVersion: MODEL_VERSION, provider: process.env.LLM_PROVIDER ?? "gemini",
    jdTitle: jd.title, roleFamily: jd.roleFamily, result, suggestions, fileType: type,
    jdSource: target.source, sampleJdId: target.sampleId, libraryVersion: target.libraryVersion, jdUrlHost: target.urlHost });
  await rl.set({ count: FieldValue.increment(1) }, { merge: true });
  console.log(JSON.stringify({ evt: "check", uid, resultId: resultRef.id, ms: Date.now() - t0, model: MODEL_VERSION, jdSource: target.source, sampleJdId: target.sampleId }));
  return NextResponse.json({ id: resultRef.id, result, suggestions, sampleNotes: target.notes });
}
```

## 8. Security, privacy and legal

- **No personal data in the library.** The JD routes are public `GET` endpoints with cache headers; they never touch Firestore or user data.
- **Link fetching is user-initiated and single-shot.** https only, public IPs only, 8 s timeout, 1.5 MB cap, at most 3 redirects, identifying user-agent, no cookies. Only the URL host is stored. FLAG: DNS-rebinding residual risk between lookup and connect — for production, route link fetches through an egress proxy or pin the resolved IP with a custom HTTP agent.
- **Third-party terms.** Some sites' terms restrict automated access. Keep fetching on-demand and per user; do not crawl, cache or republish fetched JDs. FLAG: include this in the DPDP/legal review already planned for the Resume Checker.
- **Uploaded JD files** are parsed in memory and not stored (only resumes are stored, under the existing consent flow).
- **Prompt injection.** Link, upload and paste JDs remain untrusted and keep passing through `sanitize()` and `wrapUntrusted()`. Sample JDs are trusted data and never reach the extraction LLM.
- **Copyright.** Do not add real employers' JDs to the library without permission; user-supplied JDs are used only for that user's check.
- **Honesty rules.** Always show `SAMPLE_DISCLAIMER` and the V/P/A label with sample-JD results; never imply guaranteed shortlisting or placement.
